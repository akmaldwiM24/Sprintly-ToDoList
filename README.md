# 🚀 SPRINTLY — Task & Project Management Dashboard

**SPRINTLY** is a modern, responsive task and project management dashboard built with React and Vite. It helps users organize tasks, manage projects, and monitor progress through a clean and intuitive interface.

The application is frontend-only, with data stored locally in the browser using LocalStorage.

**🌐 Live Demo:** https://akmaldwim24.github.io/Sprintly-ToDoList/

**💻 GitHub Repository:** https://github.com/akmaldwiM24/Sprintly-ToDoList

---

## ✨ Features

### 📋 Task Management
- Create, edit, and delete tasks.
- Organize tasks using a Kanban board with To Do, In Progress, and Done columns.
- Set task priorities and deadlines.
- Search tasks and filter by priority or status.
- Track task completion and overdue tasks.

### 📁 Project Management
- Create, edit, and delete projects.
- Add tasks directly to specific projects.
- Manage independent tasks without assigning a project.
- Automatically calculate project completion percentages.
- View project tasks and mark them as completed.

### 📊 Dashboard & Reports
- Dynamic task statistics.
- Project Report with completion metrics and task distribution.
- Real-time updates when task statuses change.

### 🎨 User Experience
- Responsive layouts for desktop, tablet, and mobile.
- Mobile hamburger navigation.
- Light Mode and Dark Mode.
- Theme preferences saved in LocalStorage.
- Smooth animations and interactive buttons.

### 💾 Data Management
- Persistent tasks and projects using browser LocalStorage.
- Export tasks and projects as a JSON backup.
- No account or backend required.

---

## 🛠️ Tech Stack

- **React** — Component-based user interface.
- **JavaScript (ES6+)** — Application logic and state management.
- **Vite** — Development server and build tool.
- **CSS3** — Responsive styling, custom properties, and animations.
- **React Router** — Client-side navigation.
- **LocalStorage** — Browser-based data persistence.
- **GitHub Pages** — Static website hosting.

## 🚀 Getting Started

Follow these steps to run SPRINTLY locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

**1. Clone the repository**

`git clone https://github.com/akmaldwiM24/Sprintly-ToDoList.git`

**2. Navigate to the project directory**

`cd Sprintly-ToDoList`

**3. Install dependencies**

`npm install`

**4. Start the development server**

`npm run dev`

Open the local URL displayed in your terminal.

### Production Build

To generate an optimized production build:

`npm run build`

## 🌐 Deployment

SPRINTLY is deployed using **GitHub Pages** with an automated GitHub Actions workflow.

The website is rebuilt and redeployed when changes are pushed to the main branch.

**Live Website:** https://akmaldwim24.github.io/Sprintly-ToDoList/

---

## 📝 Important Notes

SPRINTLY is a frontend-only portfolio project.

- Data is stored separately in each browser.
- Tasks and projects are not synchronized across devices.
- Clearing browser storage may remove saved data.
- The application does not require authentication or an external database.
